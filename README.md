**Ember Duel** — a 4-element card battler. Outsmart the Rival: it telegraphs the element it will play next, so you can answer it with the element that beats it. Ember beats Leaf, Leaf beats Tide, Tide beats Ember; Stone is neutral and armoured. Chain the same element twice in a row for +2 power. Both sides start at 30 life; burn the Rival's to zero.
